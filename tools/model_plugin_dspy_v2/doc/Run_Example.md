# Run Example — `tools/model_plugin_dspy_v2`

This file is a simple guide. Read it step by step when you forgot how this tool works.

---

## 1. What does this part do?

Imagine you write what you want **layer by layer** (this works best — same style as `fewshot_examples.py`):

```
Create a CNN for 28x28 images, in_features channel, n_classes = 10

Conv2d: in_features->10, kernel=5, no padding
MaxPool2d(2) -> ReLU
...
Linear: 50->n_classes
log_softmax output
```

This tool:

1. Sends your sentence to a **language model** (AI).
2. The AI writes **Python code** for a PyTorch model (`class Model(nn.Module)`).
3. The tool **checks** that the code looks OK (imports, `forward`, and a quick test).
4. It **saves** the code into one file in your project.

**Important:** This runs on **your computer while you develop**. It does **not** run inside FeatureCloud when clients train. You use it to **create** a model file. Later you point your `config.yml` at that model (or use a built-in model like `cnn.py`).

**The file it creates:**

```
plugins/models/generated_architecture/customized_model_v2.py
```

That is the main thing to remember.

---

## 2. How to run this part

### 2.1 Prepare the environment

Do these steps **once** before your first run (or when you open a new terminal).

**Step A — Open PowerShell**

**Step B — Turn on your Python environment**

```powershell
& "C:\FC\fc-deep-learning-env\Scripts\Activate.ps1"
```

You should see something like `(fc-deep-learning-env)` at the start of the line.

**Step C — Go to the project folder**

This folder must be the **root** of the app (where `main.py` and `plugins` live):

```powershell
cd "C:\FC\fc-deep-learning-master\fc-deep-learning-master"
```

**Step D — Install DSPy (if not installed yet)**

```powershell
pip install dspy-ai
```

**Step E — Make sure the AI can answer**

The tool tries cloud providers **in order**: Groq → Gemini → Cohere → Mistral → Ollama.

- API keys for Groq/Gemini/Cohere/Mistral are set in `tools/model_plugin_dspy_v2/config.py` in this project.
- **Or** you can run **Ollama** on your PC:
  - Install Ollama and start it.
  - Default address: `http://localhost:11434`
  - Default model name: `llama3.1`

Optional environment variables (only if you need to change defaults):

| Variable | What it does |
|----------|----------------|
| `FC_DSPY_OLLAMA_BASE_URL` | Ollama address (default: `http://localhost:11434`) |
| `FC_DSPY_OLLAMA_MODEL` | Ollama model name (default: `llama3.1`) |

You do **not** need to set these if Ollama defaults are fine.

**Step F — You are ready**

You need:

- Activated venv  
- Correct folder (`fc-deep-learning-master`)  
- `dspy-ai` installed  
- Internet **or** Ollama running

### 2.2 First example — CNN with a layer list (like `fewshot_examples.py`)

This prompt is the **same style** as example 1.1 in `fewshot_examples.py`.  
Copy the whole block below and run it (it can take **1–3 minutes** the first time).

**The text you send to the AI:**

```
Create an CNN architecture for image classification. The dataset contains 28x28 images with in_features channel, and the model should perform multiclass classification with n_classes = 10

Conv2d: in_features->10, kernel=5, no padding
MaxPool2d(2) -> ReLU
Conv2d: 10->20, kernel=5, no padding
Dropout2d
MaxPool2d(2) -> ReLU
Flatten to 320
Linear: 320->50 -> ReLU
Dropout
Linear: 50->n_classes
log_softmax output
```

**PowerShell command** (uses `@" ... "@` so line breaks are kept):

```powershell
python -m tools.model_plugin_dspy_v2.cli --request @"
Create an CNN architecture for image classification. The dataset contains 28x28 images with in_features channel, and the model should perform multiclass classification with n_classes = 10

Conv2d: in_features->10, kernel=5, no padding
MaxPool2d(2) -> ReLU
Conv2d: 10->20, kernel=5, no padding
Dropout2d
MaxPool2d(2) -> ReLU
Flatten to 320
Linear: 320->50 -> ReLU
Dropout
Linear: 50->n_classes
log_softmax output
"@
```

You can also use `--prompt` instead of `--request` — they mean the same thing.

---

### 2.3 What you should see after the first example

**In the terminal (screen):**

1. A line like: `Backend: groq (mixtral-8x7b-32768)` — which AI was used (yours may say `mistral`, `ollama`, etc.).
2. A line like: `Wrote model to: ...\plugins\models\generated_architecture\customized_model_v2.py`
3. The **full Python code** printed below that.

**Files and folders to watch:**

| What to watch | Why |
|---------------|-----|
| `plugins/models/generated_architecture/customized_model_v2.py` | **This is the output.** Open it in the editor. It should have a header comment (`# Auto-generated by tools/model_plugin_dspy_v2`) and a `class Model(nn.Module)`. |
| `plugins/models/generated_architecture/` | Same folder — only this file name matters for v2 (`customized_model_v2.py`). |

**Good sign:** The file exists and contains:

- `import torch`, `class Model`, and `def forward`
- `nn.Conv2d(in_features, 10, kernel_size=5)` and `nn.Conv2d(10, 20, kernel_size=5)` (like the layer list)
- `nn.Linear(320, 50)` and `nn.Linear(50, n_classes)`
- `F.log_softmax` at the end

**Bad sign:** Error about “All language-model backends failed” — check internet, API keys in `config.py`, or start Ollama.

### 2.4 Second example — MLP with a layer list (like `fewshot_examples.py`)

This prompt is the **same style** as example 5.1 in `fewshot_examples.py` (MLP, layer by layer).  
Run it after example 1 (also wait **1–3 minutes**).

**The text you send to the AI:**

```
Create an MLP architecture for multiclass classification with n_classes classes and in_features input features.

Linear: in_features->64 -> SiLU
Dropout(0.2)
Linear: 64->32 -> SiLU
Dropout(0.2)
Linear: 32->n_classes
log_softmax output
```

**PowerShell command:**

```powershell
python -m tools.model_plugin_dspy_v2.cli --request @"
Create an MLP architecture for multiclass classification with n_classes classes and in_features input features.

Linear: in_features->64 -> SiLU
Dropout(0.2)
Linear: 64->32 -> SiLU
Dropout(0.2)
Linear: 32->n_classes
log_softmax output
"@
```

---

### 2.5 What you should see after the second example

**In the terminal:**

- Again: `Backend: ...` and `Wrote model to: ...`
- New Python code printed (should use `nn.Linear` only — **no** `Conv2d` for this MLP example).

**Files and folders to watch:**

| What to watch | Why |
|---------------|-----|
| `plugins/models/generated_architecture/customized_model_v2.py` | **This file is overwritten** each time you run the tool. After example 2, it should describe an MLP, not the CNN from example 1. |
| Terminal output | Compare the printed code with the saved file — they should match. |

**Good sign:** `customized_model_v2.py` has:

- `nn.Linear(in_features, 64)` (or similar — first layer uses `in_features`)
- `nn.Linear(64, 32)` and `nn.Linear(32, n_classes)`
- `nn.SiLU` (or activation matching your list)
- **No** `nn.Conv2d` (this is an MLP, not a CNN)

**Reminder:** Each run replaces the same file. If you want to keep the CNN from example 1, copy `customized_model_v2.py` to another name **before** you run example 2.

**Tip:** More layer-list examples live in `tools/model_plugin_dspy_v2/fewshot_examples.py` (e.g. CNN 2.1 with `AdaptiveAvgPool2d`, MLP 6.1 with `BatchNorm1d`). Copy a prompt from there and paste it into `--request @"..."@`.

## Quick cheat sheet

| I want to… | Do this |
|------------|---------|
| Generate a model from English | `python -m tools.model_plugin_dspy_v2.cli --request "..."` |
| See the result | Open `plugins/models/generated_architecture/customized_model_v2.py` |
| Use the model in FeatureCloud | Set `fc_deep.model.name` in your `config.yml` to point at your plugin file (see main app docs / `Run_App.md`) |

---

## What this tool does **not** do

- It does **not** start Docker or FeatureCloud tests by itself.  
- It does **not** change `config.yml` (that is `tools/dspy` or `tools/config_plugin_dspy`).  
- It does **not** train the model — it only **writes** the model code file.

If something fails, read the error in the terminal first, then check: venv active, correct folder, `pip install dspy-ai`, and at least one AI backend working.
